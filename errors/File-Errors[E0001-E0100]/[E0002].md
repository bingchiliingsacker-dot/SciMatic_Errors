# [E0002]

## Title: ID number does not exist
#### Classification: 🟠 Euclid

* This error is encountered if the user gives an ID parameter that does not exist inside the certain file format.

## Possible Encounters

* `Database`
* `fresh_convert_curr` offline mode
* `Cache`

## Tip:

* Give a valid ID. You can get them through certain methods like:

  * Listing the available IDs in the file or database.
  * Using the appropriate `list()` or `get_ids()` method, if available.
  * Checking the file contents manually.
  * Using the corresponding lookup method before requesting a specific ID.
  * Making sure the ID belongs to the correct file format or data source.
