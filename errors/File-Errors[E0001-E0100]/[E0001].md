# [E0001]
---

## Title: File is not a supported format.
## Classification: 🟠 Euclid

- This error is encountered when an unsupported file format is provided.

## Possible Encounters

- `Cache`
- `CSV`
- `JSON`
- `PunnettSquare`

## Tips

- Set the file format to the correct format according to the class/function.
- For `Cache`: `.db` or `.json`
- For `CSV`: `.csv`
- For `JSON`: `.json`
- For `PunnettSquare`: `.csv`
