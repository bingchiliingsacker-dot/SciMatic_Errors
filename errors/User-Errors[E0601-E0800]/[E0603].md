# [E0603]

## Title: Wrong number of arguments
### Classification: 🟠 Euclid
- The user gives a certain function a wrong number of arguments.

## Possible Encounters:
- Functions like `volume_circular()` and other volume calculations in `geometry.py` that have a dynamically changing amount of arguments(from using *args).

## Tips:
- Give the right amount of arguments as instructed by the error message.
