# Title: a = 0
## Classification: 🟠 Euclid
- In the quadratic formula, a rule states that a must not equal to 0 as it will cause Zero Division Errors for later steps.

# Possible Encounters
- `quadratic_formula()`
- `quadratic_inequality()`

# Tips
- Make sure parameter a is not equal to 0
